# Proyecto ResidAurora - Exportación de Código

Este documento contiene la estructura y referencia de las pantallas diseñadas para el portal **ResidAurora**.

## Resumen del Proyecto
- **Nombre:** ResidAurora
- **Plataforma:** Portal de Gestión Residencial (Web / Mobile Responsive)
- **Stack Sugerido:** React + Tailwind CSS + Lucide Icons

## Pantallas Incluidas

### Flujo de Bienvenida
- **Escritorio:** Bienvenida con selección de perfil.
- **Móvil:** Bienvenida optimizada.

### Dashboard (Panel de Control)
- **Escritorio:** Resumen de saldo, tareas y noticias comunitarias.
- **Móvil:** Vista compacta de métricas y acceso rápido.

### Gestión de Propietarios (Administración)
- **Escritorio:** Tabla detallada con filtros por torre/piso y acciones CRUD.
- **Móvil:** Vista de tarjetas optimizada para búsqueda y edición rápida.

### Finanzas (Recibos, Gastos y Pagos)
- **Mis Recibos:** Historial de facturación y descarga de PDF.
- **Gastos Comunes:** Desglose de egresos operativos por categoría.
- **Historial de Pagos:** Validación de transacciones bancarias.
- **Realizar Pago:** Interfaz de pasarela de pago segura.

## Instrucciones para el Desarrollador
1. Todas las pantallas utilizan **Tailwind CSS** para el estilo.
2. Los íconos recomendados son de la librería **Lucide React**.
3. La fuente principal es **Inter**.
4. El sistema de diseño se basa en la paleta de colores corporativa (Residencias Aurora).
